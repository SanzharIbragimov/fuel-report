# Отчёт по расходу топлива

Инструмент загружает выгрузку телематики или путевых листов (.xlsx / .csv), сопоставляет фактический расход с линейными нормами, считает отклонения в литрах и процентах и формирует отчёт в Excel с выделением проблемных машин и водителей.

## Что умеет

- **Загрузка** .xlsx и .csv (разделитель `;` или `,`), выбор листа. Колонки распознаются по названию на русском, казахском и английском; соответствие можно поправить вручную.
- **Норма** — из файла в литрах, в л/100 км или из отдельного справочника норм по модели или госномеру. Есть зимняя надбавка к норме в процентах, если она установлена на предприятии.
- **Расчёт** — отклонение по каждой записи, машине и водителю в литрах и процентах, фактический расход на 100 км.
- **Проблемные записи:**
  - перерасход выше порога (по умолчанию > 10% и ≥ 5 л);
  - расход без пробега — возможный слив или нецелевое использование;
  - пробег без расхода;
  - расход на 40% ниже нормы.
- **Ошибки во входных данных** — сообщение с номером строки файла:
  - пустые ячейки, текст вместо числа, отрицательные значения;
  - неверные даты;
  - пустой госномер.

  Госномера приводятся к одному виду: пробелы убираются, кириллица заменяется латиницей. Номер, отличающийся от частого одним символом, считается опечаткой и объединяется с частым.
- **Отчёт Excel** — листы «Сводка», «По машинам», «По водителям», «Проблемы», «Детально», «Ошибки в данных». Проблемные строки выделены цветом, есть фильтры, страницы настроены на печать.

## Запуск

Windows: двойной щелчок по `run.bat` — при первом запуске поставятся зависимости, откроется браузер.

Вручную:

```bash
pip install -r requirements.txt
streamlit run app.py                  # веб-интерфейс, http://localhost:8501
python cli.py данные.xlsx             # без интерфейса: сразу отчёт otchet_данные.xlsx
python cli.py данные.xlsx --threshold 15 --norms samples/normy.xlsx --winter 10
```

Docker: `docker build -t fuel-report . && docker run -p 8501:8501 fuel-report`

## Пример

В `samples/` лежит вымышленный автопарк: 10 машин и 188 записей за октябрь, плюс справочник норм. В данные заложены:
- систематический перерасход у одной машины;
- разовые всплески расхода;
- два «расхода без пробега»;
- типичные ошибки ввода.

Файлы пересоздаются командой `python scripts/make_sample.py`. В интерфейсе кнопка «Попробовать на примере» загружает этот же файл.
